---

## 1. Architecture: what you get

You’ll build a Go shared library with a C ABI:

* Go side:

  * Goroutines, channels, timers, etc.
  * A small concurrency “kernel”:

    * spawn async jobs
    * join/await jobs
    * message-passing channels
    * sleep/timers
  * A registry of Go task entrypoints that you can extend over time.

* C side:

  * Talks only with **C types** (`uint64_t`, `void*`, `uint32_t`, etc.).
  * Gets opaque handles for:

    * tasks (`gt_task_t`)
    * channels (`gt_chan_t`)
  * For any new Go function you want to use asynchronously, you write a tiny Go wrapper and expose it through this kernel.

This **does** give you “power of Go’s concurrency from C” without faking that C itself is running on goroutines.

## 2. C header: core API

This is the C-facing API (`gtruntime.h`), designed to be linkable from any C program:

```c
#ifndef GTRUNTIME_H
#define GTRUNTIME_H

#include <stdint.h>
#include <stdbool.h>

#ifdef __cplusplus
extern "C" {
#endif

// --------- opaque handles ---------

typedef uint64_t gt_task_t;  // handle to an async Go task
typedef uint64_t gt_chan_t;  // handle to a Go channel of byte messages

// --------- runtime init ---------

// Optional explicit init; first call into Go will also implicitly init.
void gt_init(void);

// --------- tasks (goroutine-backed jobs) ---------

// Spawn a predefined Go task by integer ID, passing an opaque pointer argument.
// `task_id` is agreed between C and Go (like a syscall number).
gt_task_t gt_spawn(uint32_t task_id, void *arg);

// Block current thread until the given task completes.
// Returns 0 on success, nonzero on error (invalid handle etc.).
int gt_join(gt_task_t task);

// Block until all known tasks complete.
int gt_join_all(void);

// --------- channels (byte message channels) ---------

// Create a buffered channel that carries byte slices.
gt_chan_t gt_chan_create(uint32_t capacity);

// Close a channel; sends will fail, recvs will drain then report closed.
void gt_chan_close(gt_chan_t ch);

// Send a message (copy of `data[0..len)`) into the channel.
// Returns 0 on success, nonzero on closed/invalid.
int gt_chan_send(gt_chan_t ch, const void *data, uint32_t len);

// Receive a message into `buf` (up to maxlen). Actual size in *out_len.
// Returns:
//   0: success
//   1: invalid handle
//   2: channel closed, no data
int gt_chan_recv(gt_chan_t ch, void *buf, uint32_t maxlen, uint32_t *out_len);

// --------- time / sleep ---------

// Cooperative sleep; does not busy-wait, uses Go's scheduler.
void gt_sleep_ms(uint64_t ms);

#ifdef __cplusplus
}
#endif

#endif // GTRUNTIME_H
```

This is your **minimal concurrency “syscall” layer**.

Everything else (higher-level patterns) can be encoded in terms of these primitives + specific task IDs.

## 3. Go side: core runtime implementation

### 3.1. Go file `gtruntime.go`

```go
package main

/*
#include <stdint.h>
*/
import "C"

import (
	"sync"
	"sync/atomic"
	"time"
	"unsafe"
)

type taskID uint32
type taskHandle uint64
type chanHandle uint64

var (
	nextTaskID uint64
	nextChanID uint64

	tasksMu sync.Mutex
	tasks   = make(map[taskHandle]chan struct{})

	chansMu sync.Mutex
	chans   = make(map[chanHandle]chan []byte)
)

// ---------------- task registry ----------------

// Here you register all Go task entrypoints you want C to be able to spawn.
// Each entry is: func(arg unsafe.Pointer)
var taskRegistry = map[taskID]func(arg unsafe.Pointer){
	1: task_example, // you define task_example below
	// 2: task_http_worker,
	// 3: task_io_pump,
	// ...
}

// Example task implementation.
// You can do anything here: goroutines, channels, timers, etc.
func task_example(arg unsafe.Pointer) {
	// Interpret arg in some agreed struct format:
	// ptr := (*C.struct_SomeArgs)(arg)
	// do stuff...
}

// ---------------- exported functions ----------------

//export gt_init
func gt_init() {
	// Nothing required; Go runtime auto-inits on first call.
}

//export gt_spawn
func gt_spawn(task_id C.uint32_t, arg unsafe.Pointer) C.uint64_t {
	id := taskID(task_id)
	entry, ok := taskRegistry[id]
	if !ok {
		return 0 // 0 = invalid handle
	}

	h := taskHandle(atomic.AddUint64(&nextTaskID, 1))
	done := make(chan struct{})

	tasksMu.Lock()
	tasks[h] = done
	tasksMu.Unlock()

	go func() {
		defer func() {
			if r := recover(); r != nil {
				// TODO: optional logging/error hook
			}
			close(done)
			tasksMu.Lock()
			delete(tasks, h)
			tasksMu.Unlock()
		}()

		entry(arg)
	}()

	return C.uint64_t(h)
}

//export gt_join
func gt_join(h C.uint64_t) C.int {
	handle := taskHandle(h)

	tasksMu.Lock()
	done, ok := tasks[handle]
	tasksMu.Unlock()

	if !ok {
		return C.int(1) // invalid handle
	}

	<-done
	return 0
}

//export gt_join_all
func gt_join_all() C.int {
	for {
		tasksMu.Lock()
		if len(tasks) == 0 {
			tasksMu.Unlock()
			return 0
		}
		doneList := make([]chan struct{}, 0, len(tasks))
		for _, ch := range tasks {
			doneList = append(doneList, ch)
		}
		tasksMu.Unlock()

		for _, ch := range doneList {
			<-ch
		}
	}
}

//export gt_chan_create
func gt_chan_create(capacity C.uint32_t) C.uint64_t {
	h := chanHandle(atomic.AddUint64(&nextChanID, 1))
	ch := make(chan []byte, int(capacity))

	chansMu.Lock()
	chans[h] = ch
	chansMu.Unlock()

	return C.uint64_t(h)
}

//export gt_chan_close
func gt_chan_close(h C.uint64_t) {
	handle := chanHandle(h)

	chansMu.Lock()
	ch, ok := chans[handle]
	if ok {
		delete(chans, handle)
	}
	chansMu.Unlock()

	if ok {
		close(ch)
	}
}

//export gt_chan_send
func gt_chan_send(h C.uint64_t, data unsafe.Pointer, len C.uint32_t) C.int {
	handle := chanHandle(h)

	chansMu.Lock()
	ch, ok := chans[handle]
	chansMu.Unlock()
	if !ok {
		return C.int(1) // invalid handle
	}

	var buf []byte
	if len > 0 {
		buf = C.GoBytes(data, C.int(len)) // copies from C memory
	} else {
		buf = nil
	}

	// Blocking send in Go terms; doesn't block OS threads badly because
	// it's a goroutine.
	ch <- buf
	return 0
}

//export gt_chan_recv
func gt_chan_recv(h C.uint64_t, buf unsafe.Pointer, maxlen C.uint32_t, out_len *C.uint32_t) C.int {
	handle := chanHandle(h)

	chansMu.Lock()
	ch, ok := chans[handle]
	chansMu.Unlock()
	if !ok {
		return C.int(1) // invalid handle
	}

	msg, ok := <-ch
	if !ok {
		// channel closed and drained
		*out_len = 0
		return C.int(2)
	}

	n := len(msg)
	if n > int(maxlen) {
		n = int(maxlen)
	}

	if n > 0 {
		dst := unsafe.Slice((*byte)(buf), int(maxlen))
		copy(dst[:n], msg)
	}

	*out_len = C.uint32_t(n)
	return 0
}

//export gt_sleep_ms
func gt_sleep_ms(ms C.uint64_t) {
	time.Sleep(time.Duration(ms) * time.Millisecond)
}

func main() {}
```

## 4. How you “wrap any Go syntax” for C

Now the important part: **how do you expose arbitrary Go code patterns to C?**

You do it in *two layers*:

### 4.1. Add a Go task to the registry

Say you want a “HTTP worker” task:

```go
func task_http_worker(arg unsafe.Pointer) {
    cfg := (*C.struct_HttpConfig)(arg) // struct defined in a C header
    // Use cfg fields as needed (via C.* access), or copy into Go structs.

    // Spawn internal goroutines, use channels, timeouts, whatever:
    // e.g., start multiple worker goroutines:
    // go internalWorker(...)
    // go internalWorker(...)
    // block until they finish...
}
```

Then register it:

```go
var taskRegistry = map[taskID]func(arg unsafe.Pointer){
    1: task_example,
    2: task_http_worker,
    // 3: task_pipeline_runner,
    // 4: task_background_timer,
}
```

Now C can do:

```c
struct HttpConfig cfg = { /* ... */ };
gt_task_t t = gt_spawn(2, &cfg);  // 2 = HTTP worker
gt_join(t);
```

The Go code inside `task_http_worker` can itself:

* start more goroutines,
* communicate over Go channels (possibly also mapped to `gt_chan_*` where needed),
* call timers, sleep, etc.

That’s literally “any Go concurrency syntax” – just living inside that function.

---

### 4.2. Pattern to export “custom async functions” one by one

Sometimes you want **one specific Go function** to be directly usable from C in an async way. Then you define:

```go
// A concrete Go function with nice types.
func doSomethingComplex(reqID uint64, input []byte) error {
    // goroutines, channels, etc...
    return nil
}

//export gt_doSomethingComplex_async
func gt_doSomethingComplex_async(req_id C.uint64_t, data unsafe.Pointer, len C.uint32_t) C.uint64_t {
    // Pack C args into a small heap object:
    in := C.GoBytes(data, C.int(len)) // copy input for safety
    id := uint64(req_id)

    h := taskHandle(atomic.AddUint64(&nextTaskID, 1))
    done := make(chan struct{})

    tasksMu.Lock()
    tasks[h] = done
    tasksMu.Unlock()

    go func() {
        defer func() {
            if r := recover(); r != nil {
                // TODO: record error
            }
            close(done)
            tasksMu.Lock()
            delete(tasks, h)
            tasksMu.Unlock()
        }()

        _ = doSomethingComplex(id, in)
    }()

    return C.uint64_t(h)
}
```

C usage:

```c
uint8_t buf[256];
// ... fill buf ...
gt_task_t t = gt_doSomethingComplex_async(42, buf, 256);
gt_join(t);
```

You can repeat this pattern for **any Go function** you care about. That’s your “bloated library” angle: just keep adding wrappers.

## 5. How far can you push this?

With this pattern, you can:

* Use Go’s goroutines/channels/timers from C via:

  * task spawns
  * join/wait
  * message passing with `gt_chan_*`
* Implement higher-level stuff in Go and expose narrow C wrappers, e.g.:

  * worker pools
  * rate limiters
  * fan-in/fan-out pipelines
  * RPC dispatchers
  * re-implement `sync.WaitGroup` semantics at C level (wrapping Go’s `sync.WaitGroup`).

**You are not limited by C ABI types**, only by:

* your willingness to define C structs that both sides understand, and
* copying/marshalling cost where needed.

What you **still don’t get** (and realistically can’t) is:

* Arbitrary C code being scheduled as if it were a native goroutine (it always runs as a blocking cgo call).
* Go preempting C stacks, or doing cheap green-thread context switches *inside* C code.

But in practice, for “use Go’s concurrency as a service” from C, this is about as close as you can get while staying sane and production-viable.
